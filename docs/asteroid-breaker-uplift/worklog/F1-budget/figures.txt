F1's fourth frame sitting (2026-11-15): how it was made, then each script's output as it printed it.

== How it was made
Each build was checked out (detached, in a worktree of its own) and built with source maps into a folder of its own,
named <name>-dist: smbase = da697c6e9, the build's start; smp4 = c8bd5e91, the integration under F1 (the same game as
086b363c); tip3 = 278cdaeb, F1's last (the same game as c54f9ef0). In the checkout's frontend/games/asteroid-breaker:
  yarn vite build --sourcemap --outDir <folder>/<name>-dist --emptyOutDir
Each build's own code wrote its runs, into its folder, from the same checkout:
  node kept-run.mjs <name>-dist/budget-init.js <checkout>/frontend/games/asteroid-breaker/tools
  node wave-run.mjs <name>-dist/budget-tempest.js casino 29 <checkout>/frontend/games/asteroid-breaker/tools
Then, in <folder>, with YARN set to run Yarn (serve.sh, which rounds.sh calls, serves each build in turn on 9141):
  rounds.sh 14 p4w9 go.js 0 budget-init.js smbase smp4 tip3
  rounds.sh 11 p4tempest go-tempest.js 1500 budget-tempest.js smp4 tip3
  PROFILE=1 TRACE_MS=5000 rounds.sh 3 p4prof go.js 0 budget-init.js smbase smp4 tip3
  PROFILE=1 TRACE_MS=5000 rounds.sh 3 p4proftempest go-tempest.js 1500 budget-tempest.js smp4 tip3
  node split.mjs p4w9-<name>-<round>.json...   (each build's rounds, smbase's without 1 and 6)
  node parts.mjs parts-<name>.json <name>-dist p4prof-<name>-*.json
  UNDER=layer DEPTH=1 node nodes.mjs nodesL1-<name>.json <name>-dist p4prof-<name>-*.json   (and DEPTH=2, nodesL2)
  node compare.mjs <kind> <top N> base=parts-smbase.json p4=parts-smp4.json tip=parts-tip3.json
  node parts.mjs partsT-<name>.json <name>-dist p4proftempest-<name>-*.json
  node count.mjs count-w9-<name>.json <name>-dist/budget-init.js go.js 500
  node count.mjs count-tempest-<name>.json <name>-dist/budget-tempest.js go-tempest.js 1500
The page: 2,100 x 1,000 at 1x, the CPU slowed four times, Casino night; four seconds traced (five with the sampler).
Columns of a round's line: build, round, the machine's load as it began, frames.mjs' medians (ms), and from wave 9's
round 8 and Tempest's round 6 the bar's figures at the trace's end (rounds.sh printed the earlier rounds before trace.mjs
kept them).

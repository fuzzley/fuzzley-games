F2's two frame sittings (2026-11-15) and its look: how each was made, then each round as rounds.sh printed it.

== The frame: how it was made
Three builds, each checked out (detached) in the abu-f2 worktree and built with `yarn workspace asteroid-breaker
build`, its dist/ copied into a folder of its own, named <name>-dist: begin = da697c6e9, the uplift's start, which
§9's third is measured from; start = 4b7b2b59, the integration tip F2 sits on (F2's own start, ee77af2d, sends no
burrs, which Tempest's wave 29 has had since R4); last = e0623693, F2's last commit to the game. Each build's own
checkout wrote its runs into its folder, with F1-budget's scripts (copied out for begin, which predates them, its
checkout's tools folder given):
  node kept-run.mjs <name>-dist/init9.js [<checkout>/frontend/games/asteroid-breaker/tools]
  node wave-run.mjs <name>-dist/init29.js casino 29
Then, in the folder holding the builds, with PORT=9142, TMPDIR in the scratch folder and YARN set to run Yarn:
  rounds.sh 7 w9 go.js 0 init9.js start last                 (the first sitting)
  rounds.sh 5 t29 go-tempest.js 1500 init29.js start last    (the first sitting)
  rounds.sh 7 w9b go.js 0 init9.js begin start last          (the second sitting)
The page: 2,100 x 1,000 at 1x, the CPU slowed four times, Casino night, four seconds traced, as F1's.
Columns: build, round, the machine's load as it began, frames.mjs' medians (ms), the bar at the trace's end.

== The look: how it was made
F1-budget's look.mjs, a headless Chrome of its own per sitting, PORT=9142, run from a folder holding the go scripts
and the init scripts (those were not kept), as `node <F1-budget>/look.mjs <prefix> <init> <go script> ...`. The first
three sittings (zaps at 1,600 x 900: Classic felt with motion, Casino night with it and without) ran on last-dist
served by serve.sh; the rest on the game's dev server (`yarn vite --port 9142 --strictPort --host 127.0.0.1` in
frontend/games/asteroid-breaker, the worktree at e0623693), which the staged sittings need for Angular's `ng`.
Each init script is last-dist/init29.js with "casino" replaced by the palette's id (classic, casino, pastel,
midnight) and, for the zaps and the staged sittings, the stored game's field.charge set to 40, full; the knocks'
kept it as stored (5). The staged sittings logged the vent's storm boulder as "large", where go-stage.js now logs
"boulder", as the rules would: a vent's drawing doesn't read the size (blastRadiusOf() takes its heart as small).
At 1,600 x 900, CLIP=550,280,500,420 (staged) or 550,100,500,500 (zap) took the pod's corner alone.
  look.mjs <prefix> <init> go-stage.js 1600 900 <0|1> 40 0 0     (Classic felt, Casino night)
  look.mjs <prefix> <init> go-stage.js 360 640 <0|1> 45 0 0      (Soft pastel, Midnight blue)
  look.mjs <prefix> <init> go-zap.js 1600 900 <0|1> 4 0 0        (Classic felt, Casino night)
  look.mjs <prefix> <init> go-zap.js 360 640 <0|1> 6 0 0         (Soft pastel, Midnight blue)
  look.mjs <prefix> <init> go-knock.js 1600 900 0 30 0 0         (Casino night, CLIP=700,390,200,200)
  look.mjs <prefix> <init> go-knock.js 360 640 0 30 0 0          (Midnight blue, CLIP=120,230,120,120)

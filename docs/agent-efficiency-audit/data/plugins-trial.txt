A trial of the plugins and the account's skills, on 2026-11-21, Claude Code 2.1.330.

Eight sessions of one small model, each started in the folder above the clone,
where the builds' sessions start, each starting one general-purpose agent:

  claude -p "<prompt>" --model haiku --output-format json [--settings <file>] > <name>.json
  python3 scripts/first_request.py <name>.json ...

"started": the agent only replies. "opened-a-file": the agent first reads
fuzzley-games/frontend/games/snake/package.json with the Read tool.
"as-in-a-build": the session reads that file itself before it starts the
agent, as an orchestrator has by the time it starts a worker, so the agent
starts with the repository's skills in its one list.
"plugins-off": --settings names a file whose `enabledPlugins` sets each of the
seven synced plugins to false. "account-skills-off": that file also sets
`syncClaudeAiSkills` to false. --settings changes one run and writes no file.

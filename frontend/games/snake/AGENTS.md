# Snake

This rule holds for Snake, a game whose board is drawn with Phaser. The
games', in [frontend/games/AGENTS.md](../AGENTS.md), the frontend's and the
repository's apply too.

- **Before writing or changing a spec, read the `snake-testing` skill.** It
  has the fixtures that draw a run and play a game to its end, the seed that
  keeps a spec of such a game from failing one run in 70, and which Vitest
  project a spec's folder puts it in.
